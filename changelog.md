Um Changelog (Registro de Alterações) é essencial para mostrar a velocidade da sua evolução, especialmente para a entrevista de segunda-feira. Ele prova que o projeto não é estático e que você está em ritmo de "sprint" constante.

Aqui está o modelo estruturado:

📝 Changelog - Projeto JARVIS
Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

[0.2.0] - 2026-04-26
Adicionado
Integração com Discord: Implementação de um Bot via API como interface principal de usuário, permitindo comandos remotos.

Sistema de Mensageria: Fluxo de entrada e saída de dados via Webhooks entre Discord e n8n.

Status de Operação: O sistema agora consegue responder de forma autônoma e estável.

Modificado
Arquitetura do Sistema Nervoso: Refatoração dos nós do n8n para suportar a nova interface do Discord.

README: Atualizado para refletir o novo status "Beta" e a inclusão da interface de voz/chat.

Em Teste (Work in Progress)
Validação de RAG: Testes de precisão na recuperação de notas do Obsidian para garantir que a IA está consultando o "cérebro" corretamente antes de responder.

[0.1.0] - 2026-04-23
Adicionado
Arquitetura Core: Criação do fluxo inicial conectando n8n, Obsidian e LM Studio.

Ambiente Docker: Configuração do ambiente conteinerizado para garantir a persistência do sistema nervoso.

Implementação RAG: Lógica inicial de injeção de contexto baseada em arquivos Markdown.

Documentação Alpha: Criação do primeiro README detalhando a visão do projeto.

[0.0.1] - 2026-04-20
Adicionado
Concepção do Projeto: Definição da stack tecnológica e objetivo de dar um "cérebro" para IAs locais de poucos parâmetros.

POC (Prova de Conceito): Primeiros testes bem-sucedidos de comunicação via API local com o LM Studio.
